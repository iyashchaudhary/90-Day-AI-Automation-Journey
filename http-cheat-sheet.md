5 methods:

GET: data mangna (jaise koi page kholna)
POST: naya data bhejna (jaise form submit karna)
PUT: existing data ko poora replace karna
PATCH: existing data mein thoda sa update karna
DELETE: data hatana

6 status codes:

200: sab sahi gaya
201: naya data ban gaya
400: request galat hai (format ya data mein galti)
401: login ya authentication nahi hai
404: jo maanga wo mila nahi
500: server ki taraf se galti hui
