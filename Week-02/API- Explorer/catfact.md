# Cat Fact API

- Base URL: https://catfact.ninja
- Key chahiye? Nahi (public API)
- Purpose: random cat facts aur trivia provide karti hai

## Example endpoints
1. GET /fact -> ek single random fact deta hai
2. GET /facts?limit=2 -> query parameter use karke multiple facts mangwata hai

## Sample response (GET /fact) 
{"fact":"The tiniest cat on record is Mr. Pebbles, a 2-year-old cat that weighed 3 lbs (1.3 k) and was 6.1 inches (15.5 cm) high.","length":120}
